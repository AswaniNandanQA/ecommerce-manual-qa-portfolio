BUG-001: Product Not Added to Cart After Clicking Add to Cart
Bug ID
BUG-001

Bug Title
Product is not added to the shopping cart after clicking the Add to Cart button.

Module
Shopping Cart

Environment
•	Application: E-commerce Website
•	Browser: Google Chrome
•	Operating System: Windows
•	Test Type: Manual Testing

Severity
Critical

Priority
High

Preconditions
1.	The e-commerce website is accessible.
2.	The user is on the product details page.
3.	The selected product is available in stock.
   
Test Steps
1.	Open the e-commerce website.
2.	Navigate to a product details page.
3.	Select an available product.
4.	Click the Add to Cart button.
5.	Open the shopping cart.
   
Test Data
Product: Laptop

Expected Result
The selected product should be successfully added to the shopping cart, and the cart item count should update accordingly.

Actual Result
The product is not added to the shopping cart after clicking the Add to Cart button. The cart remains empty.

Reproducibility
Always (in this example scenario)

Status
Open
